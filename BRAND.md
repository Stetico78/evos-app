# EVOS — sistema visual único

## Archivo maestro

- Maestro digital: `assets/evos-brand-v2.png`.
- Formato: PNG RGB, 1254 × 1254 px.
- Identidad: EVOS tridimensional en oro sobre negro, con reflejos fucsia y azul neón.
- Este archivo se reutiliza; no se regenera, deforma, recolorea ni sustituye por variantes improvisadas.

## Aplicación

- Web y aplicaciones EVOS: `evos-brand.js` instala el mismo maestro en todas las páginas HTML.
- Cabecera web: encuadre horizontal mediante CSS, sin alterar los píxeles del maestro.
- Avatar social: usar el PNG maestro completo en formato cuadrado.
- Portes & Montajes: puede usar su emblema específico, pero debe mantener `BY EVOS`, negro, oro, fucsia y azul neón.
- Entrenamiento y demás categorías: EVOS sigue siendo la marca principal; las categorías y colaboradores aparecen como descriptor secundario.

## Colores de referencia

- Negro: `#000000`.
- Oro EVOS: `#EFCB72`.
- Fucsia neón: `#FF2BD6`.
- Azul neón: `#208CFF`.

## Reglas obligatorias

1. No estirar el logo ni cambiar su proporción.
2. Mantener fondo negro y una zona libre mínima del 8 %.
3. No colocar texto, botones o fotografías encima del logo.
4. No crear otra marca para fitness, coaching, bienestar, tarot, astrología o servicios: son líneas dentro de EVOS.
5. Verificar el resultado público después de cada cambio; un archivo preparado o guardado no equivale a una publicación correcta.
